Instrucciones

1. Abre las DevTools del navegador (F12)

2. Ve a la pestaña Console

3. Ejecuta el siguiente código para ver las features disponibles:

document.fonts.forEach(font => {
    console.log('Font:', font.family);
});

4. Compara visualmente cada sección para ver qué features producen cambios
